## 一句话简介（≤ 250 字符）

**中文：** 用图形界面生成并执行 /give /kill /fill /clone /tp 等指令，支持拼音搜索、真实方块预览、建筑蓝图（缺模组的方块自动跳过）和强制加载区块管理。仅客户端，Forge 1.20.1。

**English:** Build and run /give /kill /fill /clone /tp and more from a GUI — pinyin search, real-block ghost previews, building blueprints (blocks from missing mods are skipped) and force-loaded chunk management. Client-side, Forge 1.20.1.

- 平台上 mod 的**唯一标识（modId）是 `cmdhelper`**，发布后不要再改：它决定了玩家的配置文件夹 `config/cmdhelper/`，改了玩家的历史、蓝图、名单都会丢。
