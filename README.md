# 生存指令助手（survival-command-helper）

Minecraft **Forge 1.20.1** 的**纯客户端** mod：用图形界面生成并执行常用指令，不用背命令语法。
物品 / 方块 / 生物直接读取当前游戏和已加载模组的注册表，支持中文名、**拼音**、ID 和模组名搜索。

> 状态：开发中（`0.1.0`）。单元测试覆盖纯逻辑部分；界面、渲染和交互目前**只通过编译，尚未逐项做游戏内实测**。

## 使用

- 进入世界后按 **K**（可在按键设置里改）打开主菜单。
- 指令需要**作弊权限（OP）**。没有权限时主菜单会给出警告，服务器的拒绝原因会显示在聊天栏。
- 只装在客户端即可，服务器不需要安装。

## 功能

| 入口 | 说明 |
|---|---|
| 获取物品 `/give` | 图标网格选择，数量范围读取服务器命令树 |
| 杀死生物 `/kill` | 范围内所有实体 / 指定生物 / 最近一个 / **敌对生物** / 自定义选择器 |
| **清除敌对生物**（主菜单一键） | 先扫描周围，**只对实际存在的类型**发命令；名单和范围在「杀死生物」里配置 |
| 传送 `/teleport` | 传送自己 / 玩家到坐标或玩家 |
| 填充方块 `/fill` | 三种坐标方式；**半透明范围预览**（右键确认，左键取消）；体积上限提示 |
| 放置方块 `/setblock` | 支持朝向、上下半 |
| 复制区域 `/clone` | 实时核对源区域 / 尺寸 / 目标 / 复制后区域；自动算出 X/Y/Z 长度，可按东南西北上下移动（单位可选"格数"或"源尺寸的倍数"，填 1 就是紧挨着源区域），「用当前」可选脚下 Y-1；世界里同时预览源框和复制后框；自动判断是否需要 `force`；右侧有**复制历史**（点击填回所有输入框），并可一键**清除粘贴区**（保留与源重叠的部分） |
| 召唤生物 `/summon` | 可指定朝向 |
| 天气与时间 | `/weather`、`/time set / add / query` |
| 游戏模式 | `/gamemode`、`/difficulty` |
| 查找坐标 `/locate` | 结构 / 生物群系 / 兴趣点；结构和兴趣点显示中文名，没有的可自己起名；找到后可一键**传送过去**（远处的区域服务器还没加载时，会先升到高处让它加载，再自动落到地面） |
| 强制加载区块 `/forceload` | 列出已强制加载的区块，每个可**传送**或**取消**；也可添加、移除、查询 |
| 建筑蓝图 | 扫描一栋建筑存成蓝图（合并成最少的 fill），在别的存档里按准星放置；**缺模组的方块自动跳过**；**真实方块的半透明虚影预览**（V 键可切回彩色方框），可旋转 / 镜像 / 升降；限速执行，放完自动校验补漏；可选"同时填空气"。**不保存箱子内容和实体** |
| 历史记录 / 收藏 | 最近 20 条、收藏 50 条；每条都有**中文解释** |

通用：坐标输入后面有**粘贴框**，粘贴 `10 64 -5`、`10，64，-5`、`X: 10 Y: 64 Z: -5` 等都能自动拆进三个格子（配合主菜单的「复制坐标」）；每个界面底部有**命令预览行**（带中文解释和问题提示），缩放窗口或切换模式不会丢已填内容。

## 配置文件

都在游戏目录的 `config/cmdhelper/` 下，均为 JSON，可手动编辑：

| 文件 | 内容 |
|---|---|
| `history.json` / `favorites.json` | 历史记录、收藏的指令 |
| `hostile_types.json` | 敌对生物名单和一键清除的范围，如 `{"types":["minecraft:zombie", ...],"range":16}` |
| `locate_names.json` | 你给结构 / 兴趣点起的中文名，如 `{"abridged:bridge":"拱桥"}` |
| `blueprints/*.json` | 保存的建筑蓝图，一个文件一个；拷到另一个存档的同名文件夹即可搬过去 |

## 构建

需要 JDK 17。

```bash
./gradlew build          # 编译 + 运行单元测试，产物在 build/libs/cmdhelper-0.1.0.jar
./gradlew runClient      # 启动开发用客户端
```

安装时把 jar 放进 `mods/`，**先删掉旧版本**，否则两个同名 mod 会冲突。

## 已知限制

- 「清除敌对生物」只能发现**客户端已加载**的实体；范围超过渲染距离时会给出提示。它只按类型判断"敌对"，不区分是否正在追击。
- 强制加载的区块只能通过 `/forceload query` 获取，因此只列**当前维度**；没有 OP 权限时列表会超时。
- 下界等有基岩顶的维度里，传送只平移，保持当前高度。
- 结构的高度服务器不提供，「传送过去」会落在地表；埋在地下的结构（远古城市等）到了之后需要自己往下挖。
- 结构 / 兴趣点的中文名：原版内置了对照表，模组的需要自己起名一次。
- 拼音只覆盖 GB2312 简体常用字。
