# 生存指令助手 · Survival Command Helper

![icon](docs/icon.png)

Minecraft **Forge 1.20.1** 的**纯客户端**实用 mod：用图形界面生成并执行常用指令，不用背命令语法。
物品 / 方块 / 生物直接读取当前游戏和已加载模组的注册表，支持中文名、**拼音**、ID 和模组名搜索。

> English: [README_EN.md](README_EN.md)　|　许可证 / License：[MIT](LICENSE)　|　更新日志：[CHANGELOG.md](CHANGELOG.md)

## 安装

1. 安装 **Minecraft 1.20.1** 和 **Forge 47.x**。
2. 把下载的 `survival-command-helper-forge-1.20.1-<版本>.jar` 放进 `mods/` 文件夹（**先删掉旧版本**，否则两个同名 mod 会冲突）。
3. 进入世界，按 **K** 打开主菜单（可在"控制"里改键）。

**只需要装在客户端**，服务器不需要安装；不依赖任何其他 mod。

## 功能

| 入口 | 说明 |
|---|---|
| 获取物品 `/give` | 图标网格选择，数量范围读取服务器命令树 |
| 杀死生物 `/kill` | 范围内所有实体 / 指定生物 / 最近一个 / **敌对生物** / 自定义选择器 |
| **清除敌对生物**（主菜单一键） | 先扫描周围，**只对实际存在的类型**发命令；名单和范围在「杀死生物」里配置 |
| 传送 `/teleport` | 传送自己 / 玩家到坐标或玩家 |
| 填充方块 `/fill` | 三种坐标方式；**真实方块半透明虚影预览**（右键确认，左键取消）；体积上限提示 |
| 放置方块 `/setblock` | 支持朝向、上下半 |
| 复制区域 `/clone` | 实时核对源区域 / 尺寸 / 目标 / 复制后区域；可按东南西北上下移动（单位可选"格数"或"源尺寸的倍数"，填 1 就是紧挨着源区域），「用当前」可选脚下 Y-1；虚影预览复制后的样子；右侧有**复制历史**（点击填回所有输入框），并可一键**清除粘贴区**（保留与源重叠的部分）；自动判断是否需要 `force` |
| **建筑蓝图** | 扫描一栋建筑存成蓝图（合并成最少的 fill），在别的存档里按准星放置；**缺模组的方块自动跳过**；**真实方块的半透明虚影预览**，可旋转 / 镜像 / 升降；限速执行，放完自动校验补漏；可选"同时填空气"。**不保存箱子内容和实体** |
| 召唤生物 `/summon` | 可指定朝向 |
| 天气与时间 | `/weather`、`/time set / add / query` |
| 游戏模式 | `/gamemode`、`/difficulty` |
| 查找坐标 `/locate` | 结构 / 生物群系 / 兴趣点；结构和兴趣点显示中文名，没有的可自己起名；找到后可一键**传送过去**（远处的区域服务器还没加载时，会先升到高处让它加载，再自动落到地面） |
| 强制加载区块 `/forceload` | 列出已强制加载的区块，每个可**传送**或**取消**；也可添加、移除、查询 |
| 历史记录 / 收藏 | 最近 20 条、收藏 50 条；每条都有**中文解释**；可删除、清空 |

**通用：** 每个界面底部有**命令预览行**（带中文解释和问题提示）；填充、复制区域、蓝图的预览都显示**真实方块的半透明虚影**（**V** 键切回彩色方框）；坐标输入后面有**粘贴框**，粘贴 `10 64 -5`、`10，64，-5`、`X: 10 Y: 64 Z: -5` 等都能自动拆进三个格子（配合主菜单的「复制坐标」）；所有输入框有悬停提示；缩放窗口或切换模式不会丢已填内容。

### 按键

| 默认键 | 作用 |
|---|---|
| **K** | 打开主菜单 |
| **R** / **G** | 蓝图预览：旋转 / 镜像 |
| **PageUp** / **PageDown** | 蓝图预览：升高 / 降低一格 |
| **V** | 预览：切换真实方块 / 彩色方框 |

都可以在游戏的"控制"设置里修改。

## 限制与注意

- **仅支持 Forge 1.20.1**（47.x），不支持 Fabric 和其他游戏版本。
- **执行命令需要作弊权限（OP）。** 没有权限时主菜单会给出警告，服务器的拒绝原因会显示在聊天栏。
- **建筑蓝图**
  - 只保存**方块和它的状态**；**箱子里的物品、实体（画、展示框、盔甲架…）、告示牌文字、旗帜图案都不保存。**
  - 只能扫描**客户端已加载**的区域，建筑要在渲染距离内；一次最多约 100 万格。
  - 放完的"校验补漏"只比较**方块种类**，不比较朝向等属性；目标区域不在渲染距离内时无法校验。
  - 预览最多画 3000 个方框、6 万个方块模型；超过会改用方框。虚影的光照固定为最亮，草和树叶用固定的平原颜色。
  - 箱子、床、告示牌等由特殊渲染器绘制的方块，以及流体，预览里显示成彩色方框。
- **清除敌对生物**只能发现**客户端已加载**的实体，并按**类型**判断（不区分是否正在追击你）；范围超过渲染距离时会提示。
- **复制区域「清除粘贴区」只是填成空气，不会恢复**粘贴之前那里原来的方块。
- **强制加载**的列表只显示**当前维度**，且需要 OP 权限才能查询。
- **传送到结构：** 结构的高度服务器不提供，会落在地表；埋在地下的结构（远古城市等）到了之后需要自己往下挖。下界等有基岩顶的维度只平移，保持当前高度。
- 结构 / 兴趣点的中文名：原版内置了对照表，**模组的需要自己起名一次**（会被记住）。
- 拼音只覆盖 GB2312 简体常用字。
- 本 mod 只**发送命令**和**读取客户端已加载的世界**，不修改游戏逻辑；装了光影类 mod 时预览显示异常，按 **V** 切回彩色方框即可。

## 配置文件

都在游戏目录的 `config/cmdhelper/` 下，均为 JSON，可手动编辑：

| 文件 | 内容 |
|---|---|
| `history.json` / `favorites.json` | 历史记录、收藏的指令 |
| `clone_history.json` | 复制区域的历史（最多 30 条） |
| `hostile_types.json` | 敌对生物名单和一键清除的范围，如 `{"types":["minecraft:zombie", ...],"range":16}` |
| `locate_names.json` | 你给结构 / 兴趣点起的中文名，如 `{"abridged:bridge":"拱桥"}` |
| `blueprints/*.json` | 保存的建筑蓝图，一个文件一个；拷到另一个存档的同名文件夹即可搬过去 |

## 从源码构建

需要 JDK 17。

```bash
./gradlew build          # 编译 + 运行单元测试，产物在 build/libs/
./gradlew runClient      # 启动开发用客户端
```
